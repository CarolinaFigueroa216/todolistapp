📌 Descripción

Esta aplicación es un gestor de tareas personales (To-Do List) desarrollado en Android Studio.
Permite a los usuarios:

Agregar tareas
Visualizar tareas pendientes
Eliminar tareas
Mantener una organización básica de actividades diarias

La aplicación cuenta con una interfaz amigable, utilizando colores pastel para una experiencia visual agradable.

🛠️ Tecnologías utilizadas
Java / Kotlin
Android Studio
XML (diseño de interfaces)
